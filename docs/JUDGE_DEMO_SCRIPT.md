# Judge Demo Script (about 75 seconds)

Use the live app and read values only from the response shown on screen. Do not
prepare or narrate sample climate numbers. If an upstream source is unavailable,
show the error honestly and explain that Earth Pulse does not fill in missing
results.

| Time | Demo action and suggested narration |
| --- | --- |
| 0–8 sec | Open the homepage. “Earth Pulse helps anyone explore how climate records change at a place they care about, using real NASA data in plain language.” |
| 8–20 sec | Open **Investigate My Surroundings**. Search a place or click the map, then choose temperature and run the analysis. “The point uses NASA's nearest grid cell, not a city-wide average.” |
| 20–33 sec | Read the returned direction and rate from the actual result. Open the provenance panel. “Here are the source, NASA parameter, units, years, retrieval time, and whether this result came from cache.” |
| 33–43 sec | Choose rainfall and run it if the API is available. “We keep NASA's returned unit and show missing coverage; we do not invent or fill in values.” |
| 43–57 sec | Open **Imagine the Future**, select a place, scenario, year, and threshold, then submit. “This is a scenario-based model projection. The number of models meeting a condition is model agreement, not a guaranteed probability.” |
| 57–68 sec | Open the Research Lab and submit a short research question. Point to the returned catalogue records. “Dataset suggestions come from NASA CMR. CMR is a catalogue; this search does not mean Earth Pulse downloaded or analyzed those datasets.” |
| 68–77 sec | Open **About Earth Pulse** or **Methodology**. “The limits matter: these historical POWER records are MERRA-2 reanalysis, a model-derived grid record, and a trend alone does not tell us its cause.” |

## If a live request fails

Keep the error visible. State which upstream source could not be reached and
continue with the About or Methodology page. Do not substitute cached values
without the UI's cached label, use screenshots as if they were live responses,
or claim an unavailable result succeeded.
